# UART 串口调试工具

基于 Python + tkinter + pyserial 的单文件串口调试工具，重点是**把发出的每一条指令都记录下来**，方便排查问题、复现测试步骤。

## 运行

```bash
pip install -r requirements.txt   # 只需 pyserial
python uart_tool.py
```

Windows 下也可直接双击 `run.bat`（脚本会自动切到 UTF-8 代码页）。

环境要求：Python 3.10+（开发环境为 Python 3.15 + pyserial 3.5），tkinter 随 Python 安装。

## 界面布局

```

│ [打开串口] [刷新]            │  接收区文本                              │  记录表格 / 快捷指令表格    │

```

- 三栏布局：左侧「串口设置」，中间「接收区 + 发送区」，右侧常驻「发送记录 / 快捷指令」，发完一条指令就能立刻在右边看到记录、双击载入或重发，不用来回切标签页。
- 两条分隔条都可拖动，位置随 `config.json` 的 `sash_pos`（两个整数）记住，下次启动保持上次的位置；左栏最窄 250 px，窗口缩到最小 1100×680 时三栏仍然都可用。
- 右侧面板很窄时表格会自动出现横向滚动条，窗口拉宽后文本 / HEX 列自动伸展。
- 串口下拉在左栏独占一整行并随左栏拉伸；放不下的完整设备信息在下方「当前选择」里换行显示，下拉列表还会按最长条目自动加宽。

## 打包成 exe

打包机只需装一次 PyInstaller（脚本会自动处理）：

```bat
python -m pip install pyinstaller
```

### 一键打包

双击 `build_exe.bat`，或用命令行执行：

```bat
build_exe.bat
```

脚本会检查 PyInstaller、清理 `build/` 与 `dist/`、再打包，产物为：

```
dist\uart_tool.exe        # 约 13 MB，单文件，目标机器无需安装 Python
```

### 手动打包

```bat
python -m PyInstaller --noconfirm --clean --onefile --windowed --name uart_tool uart_tool.py
```

- `--onefile`：打成单个 exe，方便拷贝；首次启动要把运行时解压到 `%TEMP%`，约 1~3 秒才出窗口。
- 想要**秒开**可去掉 `--onefile`（即 `--onedir`），产物是 `dist\uart_tool\uart_tool.exe` + `_internal\` 目录，需要整目录一起拷贝。
- `--windowed` 表示不带黑色控制台窗口；若双击没反应，先用 `--console` 重打包查看报错。
- 想换图标加分号参数：`--icon app.ico`。

### 打包版的行为

- `config.json` 与 `logs/` 生成在 **exe 所在目录**（`_app_dir()` 对冻结环境做了处理），不会写进临时解包目录；把 exe 拷到别的电脑，记录和配置就从零开始。
- 建议把 exe 放在可写目录（如 `D:\Tools\uart\`）；放进 `Program Files` 这类受保护目录时，配置和日志可能因权限写不进去。
- 实测环境：Python 3.15.0 + PyInstaller 6.22.3，产物可正常启动、关闭时在 exe 同目录落盘 `config.json`。
- 部分杀毒软件会对 PyInstaller 单文件误报，可加白名单，或改用 `--onedir` 规避。

## 功能

### 串口连接
- 自动枚举串口并显示设备描述（`COM3 · USB-SERIAL CH340`），按 `F5` 或点「刷新」重新扫描。
- 串口按 `COM` 号自然排序（`COM2` 在 `COM10` 之前），并去掉 Windows 描述里重复的 `(COM3)` 尾巴。
- 下拉下方一行显示**完整信息**：`设备名 | 描述 | 厂商 | VID:PID + LOCATION`，同型号多路设备（例如 4 个 Quectel 口）也能一眼分清。
- 上次选中的串口会按设备名（`COMx`）恢复，即使描述文字变了也不会丢选择。
- 波特率可下拉选择，也可直接输入自定义值；数据位 / 校验位 / 停止位 / 流控（RTS-CTS、XON-XOFF）均可配置。
- 连接后可勾选 DTR / RTS；连接期间参数控件自动禁用，避免误改。
- 串口被拔出等异常会自动断开并提示，不会卡死界面。

### 数据收发
- 接收区支持文本 / HEX 显示切换，可开关时间戳、自动滚动。
- 发送区支持文本与 HEX 两种格式；HEX 允许 `0x01, 03-0A` 这类混合分隔写法，只要求最终是偶数个十六进制字符。
- 可选「追加 CRLF」、编码可选 UTF-8 / GBK / Latin-1。
- 「定时发送」按设定毫秒间隔重复发送当前内容；串口异常或内容非法时自动停止。
- 接收内容可一键保存为 txt，接收区最多保留 5000 行防止内存膨胀。

### 发送记录（核心，窗口右侧）
- 每发送一次就记录一条：时间（含毫秒）、格式、字节数、文本预览、完整 HEX。
- 表格最多保留最近 500 条，倒序排列（最新在最上面），并写入 `config.json`，下次启动仍在。
- 选中记录后可：**重新发送**、**载入发送区**（改完再发）、**复制 HEX**、**导出 CSV**。
- 双击某条记录 = 载入左侧发送区。

### 快捷指令（窗口右侧）
- 列表只有「名称 / 内容」两列；文本 / HEX 格式在新增、编辑对话框里勾选，不再占用列宽。
- 新增时名称可以留空：自动按内容命名（HEX 指令加 `HEX` 前缀，文本取前 24 个字，内容为空时用「指令 N」）。
- 双击即发送，也可用「发送选中指令」按钮。
- 支持新增 / 编辑 / 删除，随**当前配置文件**持久化；换一个配置文件就换一套指令列表。

### 配置文件（不同项目各一套指令）
- 左栏「打开日志目录」旁边是「选择配置」按钮，可打开任意 `*.json` 配置文件。
- 切换后串口参数、各类勾选项、分隔条位置、发送记录、快捷指令一起切过去，状态栏会提示当前文件与指令条数。
- 选择结果记在默认 `config.json` 的 `active_config` 里，下次启动自动沿用；切回默认配置时该字段会被清掉。
- 想给不同项目各备一套指令：把 `config.json` 复制成 `project_a.json`，改掉里面的 `quick_commands`（可以顺手清空 `history`），再用「选择配置」切过去即可。
- 注意：切换配置会同时切换界面上的发送记录（记录本身仍保存在各自文件里，不会互相覆盖）；串口已打开时，新参数在下一次连接时生效。
- 选到损坏或非本工具生成的 JSON 会弹窗提示并保持当前配置不变。

### 日志
- 默认开启，按天写入 `logs/uart_YYYYMMDD.log`，收发都记，行格式：

  ```
  2026-10-23 14:32:58.205 TX 01 03 00 0A | \x01\x03\x00\n
  ```

- 左栏提供「打开日志目录」按钮；写盘失败会自动关闭记录并在状态栏提示，不影响收发。

## 快捷键

| 快捷键 | 作用 |
| --- | --- |
| `Ctrl + Enter` | 在发送区发送当前内容 |
| `Ctrl + ↑` | 取回上一条发送记录（连续按可继续往前翻） |
| `F5` | 刷新串口列表 |
| `Esc` | 关闭快捷指令编辑对话框 |

## 文件说明

| 文件 | 说明 |
| --- | --- |
| `uart_tool.py` | 全部程序逻辑（单文件，约 2100 行） |
| `config.json` | 运行后自动生成：串口参数、各类勾选项、分隔条位置、发送记录、快捷指令；`active_config` 记录上次选择的配置文件 |
| 其他 `*.json` | 可选：用「选择配置」切换的其它配置，各自拥有一套快捷指令 / 发送记录 |
| `logs/` | 运行后自动生成：按天存放收发日志 |
| `requirements.txt` | 依赖清单（pyserial） |
| `run.bat` | Windows 启动脚本 |
| `build_exe.bat` | Windows 一键打包脚本（PyInstaller） |
| `dist/` | 打包产物目录，`dist\uart_tool.exe` 可直接分发 |

`config.json` 与 `logs/` 已加入 `.gitignore`，属于本机运行数据。

## 实现要点

- 串口读取在守护线程中完成（`SerialLink`），收到的数据和解码文本通过 `queue.Queue` 交给界面线程，界面每 40 ms 轮询一次，避免跨线程操作 tkinter。
- 文本解码使用 `codecs.getincrementaldecoder`，多字节字符被拆包时不会出现乱码；切换编码会重建解码器。
- 配置保存做了 800 ms 去抖（`_schedule_config_save`），频繁发送时不会反复写盘；退出时同步落盘。
- 三栏用水平 `ttk.PanedWindow` 的三个 pane 实现，两条分隔条位置存成 `sash_pos: [左栏宽, 右侧起点]`，恢复时按窗口宽度做上下限裁剪，窗口缩小也不会把某一栏挤没。
- 切换配置文件时先 `_flush_config_save()` 把挂起的延迟保存落到旧文件，再读入新文件并刷新界面；「当前用哪个配置」写在默认 `config.json` 的 `active_config` 里，不写进被选中的文件本身，避免配置之间互相污染。
- 接收区裁剪、日志写入都做了异常兜底，长时间运行、磁盘只读等场景不会让界面报错退出。
